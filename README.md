# 🌤️ Weather App

A simple Python-based Weather App that allows users to check weather information for a selected location.

This project was created to practice Python programming, user input, API integration, and working with weather data.

## 🚀 Features

- 🌍 Search weather information by location
- 🌡️ Display current temperature
- ☁️ Display weather conditions
- 💧 Show humidity information
- 💨 Display other available weather details
- 🖥️ Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Weather API
- API Requests
- JSON
- Python Libraries
